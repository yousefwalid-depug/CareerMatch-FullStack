# CareerMatch

**Know Your Fit. Build What's Missing.**

CareerMatch is an AI-assisted CV-to-job matching platform designed for students, fresh graduates, and entry-level candidates.

Instead of only giving candidates a match percentage, CareerMatch explains **why** they match a job, identifies missing requirements, and generates a structured **Improvement Plan** showing what they should build next.

---

## Overview

CareerMatch allows a candidate to:

1. Browse available jobs.
2. Select a job opportunity.
3. Upload a CV in PDF format.
4. Extract a structured candidate profile.
5. Compare the candidate profile with the selected job.
6. Calculate a deterministic CareerMatch score.
7. Identify matched and missing skills.
8. Generate a prioritized Improvement Plan.

The main product idea is:

> **The match score tells you where you stand.  
> The Improvement Plan tells you what to do next.**
